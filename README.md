# BTODSTARLNUNPRH_EVTGEN_Model
An EvtGen-based Monte Carlo simulation model for new-physics scenarios with right-handed neutrinos. This model includes two new-physics parameters: $C^{RR}$, the Wilson coefficient for the right-handed vector interaction, and $M_{N_R}$, the mass of the right-handed neutrino.

When using this Monte Carlo tool, please cite B. Bhattacharya, T. E. Browder, L. M. Cremaldi, H. C. Ledesma, N. Das, A. Datta, T. Kapoor, K. Pandey, and A. Sibidanov, "A massive right-handed sterile neutrino in three-body ${\bar B}\to D^*\ell^-{\bar N}_R$ decays - a Monte Carlo simulation study," to appear on the arXiv
